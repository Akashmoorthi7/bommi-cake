# 🎂 Bommi Cake — Comic Book Style Cake Ordering Platform

A modern, high-energy cake-ordering web application for **“Bommi Cake”**, featuring a vibrant **Comic Book / Pop Art** aesthetic (halftones, speech bubbles, sound effect bursts, bold outlines, and hard drop shadows).

## 🚀 Live Access

The application is actively running on the local server:
- **Local URL**: [http://localhost:5173/](http://localhost:5173/)
- **Network URL**: `http://192.168.1.7:5173/`

---

## 🎨 Comic Book Visual Styling
- **Comic Fonts**: Google Fonts `Bangers` (headings & action bursts), `Comic Neue` (body & dialogues), and `Permanent Marker` (accents & plaques).
- **Hard Drop Shadows**: Characteristic comic shadows (`box-shadow: 4px 4px 0px #000`, `8px 8px 0px #000`).
- **Halftone Textures**: Custom SVG/CSS radial halftone dots pattern and action line gradients.
- **Action Bursts & Stickers**: Starburst polygons for `WOW!`, `YUM!`, `NEW!`, `POW!`, `BOOM!`, and `ORDER NOW!`.
- **Sound Effects Synthesizer**: Built-in Web Audio API sound generator (punchy pops, comic pows, victory fanfare) with an easy Mute/Unmute toggle in the top bar.

---

## ⚡ Core Ordering Flow
**Login → Choose Cake → Customize → Delivery Details → Payment → Order Confirmation**

1. **Login / Sign Up**:
   - Attractive comic login screen with Mobile Number and Email support.
   - 1-Click Superhero Demo accounts (`Captain Priya`, `Alex Wonder`) for rapid testing.
   - Automatically directs to the cake customizer or checkout upon authentication.

2. **Cake Catalog & Categories**:
   - 🎂 **Birthday Cakes**
   - 💒 **Wedding Cakes**
   - 💖 **Anniversary Cakes**
   - 📸 **Photo Cakes** (with simulated edible photo uploader)
   - 🎨 **Custom Cakes**
   - 🍫 **Chocolate Cakes**
   - 🦸‍♂️ **Kids Cakes**

3. **Interactive Cake Customizer**:
   - Dynamic cake size/weight scaling (0.5 kg, 1 kg, 1.5 kg, 2 kg, 3 kg tiered) with live price updates.
   - Flavor picker (Belgian Ganache, Red Velvet, Lotus Biscoff, Alphonso Mango, etc.).
   - 100% Eggless / Pure Vegetarian toggle.
   - Live piped message preview on a fondant plaque.
   - Delivery date picker (Today Express, Tomorrow, Custom).
   - Time slots (⚡ Rocket Express 2-Hours, Morning Rush, Afternoon, Evening, Midnight Surprise).
   - Party Add-ons (Free comic candles, cake knife, party poppers, sparklers).
   - **ORDER NOW** (instant 1-step checkout) or **ADD TO CART**.

4. **Cart & Rocket Checkout**:
   - Real-time cart drawer with customization breakdown.
   - Comic discount coupons (`POW20` for 20% OFF, `BOMMI100` for ₹100 OFF).
   - Recipient address selection (prefilled from user HQs).
   - Secure payment options: **UPI (GPay / PhonePe / QR)**, **Cards / Netbanking**, and **Cash on Delivery (COD)**.

5. **Order Confirmation & Comic Celebration**:
   - Full-screen confetti explosion with celebratory sound fanfare.
   - Comic Order ID (e.g. `#BOMMI-9821`).

6. **Customer Dashboard & 4-Stage Comic Strip Tracking**:
   - **Panel 1: 🥣 Batter Whisked!**
   - **Panel 2: 🔥 In the Oven!**
   - **Panel 3: 🎂 Comic Icing & Art!**
   - **Panel 4: 🚀 Rocket Delivery!**
   - 1-Click **REORDER NOW** button on past orders.
   - Saved delivery headquarters manager.
   - Profile settings and superhero avatar customizer.

7. **WhatsApp Support**:
   - Floating comic bubble with interactive popover for direct inquiries with Chef Bommi.
